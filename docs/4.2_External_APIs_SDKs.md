# 4.2 External APIs/SDKs

This document describes the third-party APIs and SDKs used in the SoleMate project implementation.

| API and version | Description | Purpose of usage | API endpoint/function/class used |
|----------------|-------------|------------------|----------------------------------|
| Firebase Admin SDK (version 12.6.0) | Backend Firebase services for authentication, database, and storage | Server-side authentication token verification, Firestore database access, and file storage management | `admin.initializeApp()`, `admin.auth()`, `admin.auth().verifyIdToken()`, `admin.firestore()`, `admin.storage().bucket()` |
| MongoDB/Mongoose (version 8.7.0) | NoSQL database and ODM (Object Document Mapper) for Node.js | Persistent data storage for products, users, try-on history, custom skins, and outfit matches | `mongoose.connect()`, `Schema`, `Model.create()`, `Model.find()`, `Model.findOneAndUpdate()`, `Model.deleteOne()`, `Model.populate()` |
| Redis/ioredis (version 5.4.1) | In-memory data structure store for caching | Session management, caching frequently accessed data, and improving API response times | `new Redis()`, `client.get()`, `client.set()`, `client.del()`, `client.exists()` |
| Express.js (version 4.19.2) | Web application framework for Node.js | RESTful API server, routing, middleware handling, and HTTP request/response management | `express()`, `Router()`, `app.use()`, `app.get()`, `app.post()`, `app.put()`, `app.delete()`, `express.json()` |
| Multer (version 1.4.5-lts.1) | Middleware for handling multipart/form-data file uploads | Processing file uploads for custom skins, outfit images, and user-generated content | `multer()`, `multer().single()`, `multer().array()`, `multer().fields()` |
| Firebase Core (version 3.6.0) | Core Firebase SDK for Flutter applications | Firebase initialization and configuration across the Flutter application | `Firebase.initializeApp()`, `DefaultFirebaseOptions.currentPlatform` |
| Firebase Auth (version 5.3.1) | User authentication service for Flutter | User registration, login, logout, and authentication state management | `FirebaseAuth.instance`, `createUserWithEmailAndPassword()`, `signInWithEmailAndPassword()`, `signOut()`, `authStateChanges()`, `currentUser`, `getIdToken()` |
| Cloud Firestore (version 5.4.0) | NoSQL cloud database for Flutter | Client-side database operations for user profiles and real-time data synchronization | `FirebaseFirestore.instance`, `collection()`, `doc()`, `set()`, `get()`, `snapshots()` |
| Firebase Storage (version 12.0.0) | Cloud storage service for Flutter | Uploading and downloading user-generated images, custom textures, and AR snapshots | `FirebaseStorage.instance`, `ref()`, `putFile()`, `getDownloadURL()`, `delete()` |
| HTTP package (Dart) | HTTP client library for making REST API requests | Communication between Flutter app and backend API for catalog, try-on history, and outfit matching | `http.get()`, `http.post()`, `http.put()`, `http.delete()`, `Uri.parse()`, `jsonEncode()` |
| Google ARCore (version 1.46.0) | Augmented reality SDK for Android | World tracking, plane detection, hit testing, anchor placement, and camera pose estimation for AR shoe try-on | `Session`, `Session.configure()`, `Frame`, `Frame.acquireCameraImage()`, `Plane`, `Anchor`, `HitResult`, `Trackable`, `TrackingState` |
| MediaPipe Tasks Vision (version 0.10.14) | Machine learning framework for pose detection | Real-time human pose estimation and foot landmark detection for accurate shoe placement in AR | `PoseLandmarker`, `PoseLandmarker.createFromOptions()`, `PoseLandmarkerResult`, `RunningMode.LIVE_STREAM`, `RunningMode.IMAGE`, `BaseOptions`, `NormalizedLandmark` |
| Filament (version 1.65.2) | Real-time physically based rendering engine | 3D shoe model rendering, lighting, materials, and scene management in AR view | `Engine`, `Scene`, `View`, `Camera`, `Renderer`, `Material`, `gltfio` (for GLB/GLTF model loading) |
| TensorFlow Lite (version 2.16.1) | Lightweight machine learning inference framework | On-device ML model execution for pose estimation and other ML tasks (used by MediaPipe) | `Interpreter`, `Tensor`, `Delegate` (GPU acceleration via `tensorflow-lite-gpu`) |
