# SoleMate
An AR-based mobile application for virtual shoe try-on with outfit matching, personalized skins, and a virtual try-on closet.

---

## Overview
SoleMate is a mobile-based AR application designed to enhance the online footwear shopping experience.  
Key features include:
- **AR Try-On**: Real-time overlay of shoes on the user’s feet using ARCore.
- **Outfit Matching**: Suggests complementary footwear based on outfit colors and styles.
- **Personalized Skins**: Users can customize shoe designs and preview them in AR.
- **Try-On Closet**: Saves try-on history for easy comparison and reuse.

---

## Tech Stack
- **AR Frameworks**: Snap Lens Studio
- **Computer Vision**: OpenCV, MediaPipe, YOLOv8 Fashionpedia, OpenAI CLIP
- **Machine Learning**: TensorFlow Lite (on-device lightweight models)
- **3D Assets**: Blender (custom models), Sketchfab/TurboSquid (sourced models)
- **Mobile Development**: Android Studio (Java/Kotlin)
- **Database**: Firebase Firestore (cloud) + SQLite (local storage)
